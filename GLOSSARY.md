# Purpose

This glossary defines the canonical terminology used throughout *The Agent Engineering Handbook*.

Its purpose is to ensure consistent vocabulary across all chapters, diagrams, examples, Architectural Decision Records (ADRs), and reference implementations.

If a term is defined here, authors MUST use the glossary definition consistently throughout the handbook.

When a definition evolves, the glossary is updated first, followed by the affected chapters.

---

# Organization

Terms are listed alphabetically.

Each entry follows the same structure:

- Definition
- Why it matters
- Related terms
- First introduced in
